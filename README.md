### Alexandre Pohl

**AI engineer. I orchestrate AI agents and ship them to production.**

I came from post-production, where every project ran on a structure: numbered folders, clear handoffs, a pipeline adapted to each client. After about 16 years making content for brands, I brought that habit to software. I define what "done" means and orchestrate coding agents through a **Plan → Implement → Validate** loop until the result holds up in production.

**What I work on**
- AI agents that run in production, with tools, guardrails and a person in the loop where it matters
- Evaluating AI agents with simulated users and test harnesses
- Agentic workflows for media: AI agents inside professional video tools, semantic search over video archives

**How I work**
Agent-first. I design the architecture, write the specs and acceptance criteria, and review what the agents produce. Decisions get written down, and features ship behind tests or evals.
→ The method: [`agentic-harness`](https://github.com/alexandrepohl/agentic-harness)
